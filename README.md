# Expense Tracker

A simple Command-Line Expense Tracker built using Python.

##  Features
- Add new expenses
- View all saved expenses
- Calculate total expenses
- Store expense data in a CSV file

## Technologies Used
- Python
- CSV Module
- File Handling

##  Project Structure

ExpenseTracker/
│
├── expense_tracker.py
├── expenses.csv
└── README.md

## How to Run

1. Clone the repository

```bash
git clone https://github.com/GeethaLasyaN/Expense-Tracker.git
```

2. Navigate to the project folder

```bash
cd Expense-Tracker
```

3. Run the program

```bash
python expense_tracker.py
```

##  Sample Menu

```text
1. Add Expense
2. View Expenses
3. View Total Expenses
4. Exit
```
